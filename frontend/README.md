# Polly Voice Frontend

Giao diện React 19 + TypeScript + Vite cho Text to Speech, Speech to Text, lịch sử và xác thực Cognito.

```powershell
Copy-Item .env.example .env
npm install
npm run dev
```

Mở `http://localhost:5173`.

Build production:

```powershell
npm run build
```

Kết quả nằm trong `dist`. Xem hướng dẫn local và AWS đầy đủ trong [README gốc](../README.md).
